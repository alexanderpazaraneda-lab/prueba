Portafolio Personal

Proyecto de portafolio personal desarrollado como evaluación práctica del módulo Desarrollo Web Front-End.

Descripción
Este sitio web presenta mi perfil personal y profesional en una sola página. Incluye navegación interna, sección sobre mí, tabla de habilidades, galería de proyectos, formulario de contacto y footer.

Tecnologías usadas
- HTML5
- CSS3
- Git
- GitHub

Cómo ejecutar
1. Clonar o descargar este repositorio.
2. Abrir el archivo `index.html` en el navegador.
